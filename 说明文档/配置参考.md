# 配置参考手册

项目里所有可变的量都在 4 个 ini 里：`项目配置.ini`（项目名 / 店铺 / 平台选择 / 判定阈值 / 通知阈值 / 运行时段 / 自检 / 提示 / 公共源）、`平台/<site>/配置/<product>.ini`（组织码、cookie 字段、浏览器实例）、`数据/库内数据/连接配置.ini`（MySQL 与两张表名）、`通知配置.ini`（企微群机器人）。它们由 `项目配置.py`、`库内导出.py`、`通知.py` 三处分别读取，**没有任何键写在代码里**。改完任何 ini 的第一件事都是跑 `python 项目配置.py`：它会打印全部生效值；配置有问题时以退出码 2 中止（`_公共/业务/项目配置.py:375-380`），结尾不出现「全部检查通过。」就是没通过。注意它只校验前两个 ini，`连接配置.ini` / `通知配置.ini` 要单独验（见第 3、4 节）。

**路径简写**（下文 `文件:行号` 只用这些简称，行号取自当前版本，源码改动后需复核）：`项目配置.py`/`每日对账.py`/`自动对账.py`/`写入日监控.py`/`排查.py` = `_公共/业务/`；`路径.py`/`通知.py`/`契约.py`/`版本.py`/`自检.py` = `_公共/监控内核/`；`库内导出.py`/`凭证刷新.py`/`平台取数.py` = `_公共/平台/小红书/聚光/`；`启动取数浏览器.py` = `_公共/运行/`；`模板/x.ini` = `模板/`。

## 1. `项目配置.ini`（项目级，必填）

放在项目根（`项目配置.py:33`）。读取顺序：先本项目文件、再平台 ini，同名段永远以本项目为准（`项目配置.py:69-75`）——所以在平台 ini 里复制一份 `[店铺]` 不会报错，只会被**静默忽略**。

| 键名 | 必填/可选 | 默认值 | 格式与约束 | 谁读它 | 填错会怎样 |
|---|---|---|---|---|---|
| `[项目] name` | 必填 | — | 任意文本，进看板标题与告警标题 | `项目配置.py:122` → `自动对账.py:66`、`写入日监控.py:286` | 空 → 启动即报「段缺少 name」（`项目配置.py:99-105`）；**写错客户名不报错，标题顶着别人名字发出去（静默）** |
| `[平台] site` | 可选 | `小红书` | 目录名，决定 `平台/<site>/` | `路径.py:65,73` | **留空或整段删掉 → 静默退回「小红书」（`路径.py:59,65`）；写错 → 指向不存在的目录，启动报「找不到平台配置文件」（`项目配置.py:46-50`）** |
| `[平台] product` | 可选 | `聚光` | 同时是 ini 文件名、适配脚本目录名 | `路径.py:66,75,78-82` | 同上；写错 → 找不到 `平台/<site>/配置/<product>.ini` → 启动报错 |
| `[店铺] list` | 必填 | — | 逗号分隔（`项目配置.py:117-118`），**顺序 = 看板列序，主店铺排第一** | `项目配置.py:126` → `库内导出.py:47`、`平台取数.py:78`、`每日对账.py:49` | 空 → 报错（`项目配置.py:128-129`）；与库内 `shop_name` 逐字不一致 → **整店行被静默过滤**（`每日对账.py:108,142`），天天报「库内未导」；`每日对账` 有 `契约.check_shops` 双向兜底（`每日对账.py:319-324`，退出码 6），**但 `写入日监控.py:52` 侧没有这层兜底，取不到就静默按 0 处理** |
| `[店铺] main` | 必填 | — | 必须是 `list` 里的某一项 | `项目配置.py:127-132` | 不在 `list` → 报错（`项目配置.py:130-132`）；**不在第一位不报错：列序即看板列序，代码不校验顺序 —— 静默错位** |
| `[对账阈值] abs_tol` | 必填 | — | 浮点，≥0 | `项目配置.py:183` → `每日对账.py:66`、`写入日监控.py:57`、`排查.py:48` | 非数字 → 报错（`项目配置.py:108-114`）；负数 → 报错（`项目配置.py:202-203`）；**填大 → 真实缺口被判「正常」，全程不报错** |
| `[对账阈值] rel_tol` | 必填 | — | 浮点，≥0 | 同上 | 同上；**填大 → 比例容差吞掉缺口，静默** |
| `[对账阈值] acc_min_ratio` | 必填 | — | 0 < x ≤ 1 | `项目配置.py:185` → `每日对账.py:68`、`写入日监控.py:58` | 越界 → 报错（`项目配置.py:199-201`）；**调小 → 采集中被当成真停投，静默误判** |
| `[对账阈值] acc_min_fill` | 必填 | — | 0 < x ≤ 1 | 同上 | 同上；**调小 → 同上** |
| `[对账阈值] acc_min_base` | 必填 | — | 整数，账户数 | `项目配置.py:187` | 非整数 → 报错；**调大 → 小店永远不判，采集问题静默漏掉** |
| `[对账阈值] ingest_fresh_min` | 必填 | — | 整数，分钟 | `项目配置.py:188` | 非整数 → 报错；**调小 → 正在写入的库被判成已采完，拿半成品判定** |

| `[运行时段] window` | 可选 | 空=不限制 | `HH:MM-HH:MM`，可跨午夜（`项目配置.py:221-236`） | `项目配置.py:216-236` → `自动对账.py:176` | 格式错 → 报错（`项目配置.py:222-235`）；**区间合法但写歪（如 `00:00-07:00`）→ 自动任务静默跳过、退出码 0**（`自动对账.py:176-180`） |

| `[公共] source` | 可选 | 空=不检查 | 路径，相对项目根即可 | `版本.py:67-80` | **指错目录只打印一行 `?`，不拦流程**（`版本.py:104-107,95-98`） |

## 5. 平台 ini 的特殊性：`店铺 = 组织码 | 分组`

1. **格式**：一行一个店铺，等号右边用 1 个 `|` 分成「组织码」「分组名」两段，多一段少一段都报错（`项目配置.py:141-145`），报错会指出实际写错的那个文件（`_sec_path()`，`项目配置.py:87-96`）。
2. **组织码必须纯数字**：`_org.isdigit()`（`项目配置.py:147-151`）。被 Excel 改成科学计数法、带空格、带前导 `=` 都过不去。
3. **分组名 = 段名去掉「凭证」前缀**（`项目配置.py:277`）：`[凭证A]` → 分组 `A`。所以 `[平台账号]` 里写 `A` 必须真的存在 `[凭证A]`（`项目配置.py:292-299`），否则启动报错。
4. **分组名下不能空**：每一个 `[凭证*]` 段至少要分到一家店，否则报错（`项目配置.py:301-305`）——「只配一个分组」就删掉另一段（`模板/聚光.ini:22`）。
5. **一个分组 = 一个浏览器实例 = 一个登录子账号**：接口按子账号隔离，端口必须各不相同（`项目配置.py:308-310`）。
6. **别用「凭证」开头的自定义段名**：`[凭证说明]`、`[凭证注意]` 都会被当成实例去要 `name/port/curl/browser/profile`，启动即报缺键（`项目配置.py:273-274,279-283`）。

## 7. 配置项之间的隐含约束

- **`[店铺] list` 与 `[平台账号]` 必须一一对应**：`list` 里每家店都要有组织码（`项目配置.py:154-158`），但反过来多出来的账号行不报错、直接丢弃（`项目配置.py:161`）。
- **`main` 必须属于 `list`**（`项目配置.py:130-132`），且按约定排第一（`模板/项目配置.ini:34,40`）——后者纯靠人守。
- **`[店铺] list` 的顺序就是看板列序**（`项目配置.py:125`、`写入日监控.py:52`）。加店只能追加到末尾，否则整张看板列位平移。
- **凭证分组名必须被引用**：`[凭证*]` 段一旦存在就必须有店指向它（`项目配置.py:301-305`），删店后忘了删段 = 开跑就报错。
- **`[平台]` 决定另外两个文件的位置**：改 `site/product` = 同时改平台 ini 与适配脚本目录（`路径.py:73-82`），旧目录不会跟着搬。
- **`simple` 留空 = 没有这一路，不是填假表名**（`模板/连接配置.ini:22-23`、`库内导出.py:141-148`）：留空后导出、对账导出步骤、契约校验三处都跳过（`契约.py:268-269`）。
- **`[tables]` 段不能省**：省了不报错，`standard` 会落到内置默认表名（`库内导出.py:134`）。
- **`ingest_stale_h` 与 `ra_active_min` 是一对**：前者失效判断靠不住时，后者会恒为真（`模板/项目配置.ini:69-73`）。
- **`[自检] forbid` 与新项目强绑定**：源头项目可留空，复制出的项目必须填（`模板/项目配置.ini:105-108`、`项目配置.py:368-369`）。
- **编码**：三个被 `项目配置.py` / `通知.py` 读的 ini 按 `utf-8-sig` 读，记事本带 BOM 也行（`项目配置.py:58`、`通知.py:37`）；**`连接配置.ini` 按 `utf-8` 读（`库内导出.py:106`），带 BOM 会解析失败**。

## 8. 改了配置要做什么

1. **必跑**：`python 项目配置.py`。看到「全部检查通过。」才算过；否则按提示改到过为止（退出码 2 = 配置错误，`项目配置.py:375-380`）。
2. **动了表名 / 库连接**：先 `python 库内导出.py --check`（`库内导出.py:490-493`），它会逐个打印 `[tables]` 每一项是「留空跳过」还是真去查表（`344-347`）。
3. **动了店铺名单 / 阈值 / 时段**：跑 `python 每日对账.py --no-write` 只对账、不改 Excel（`每日对账.py:171`），确认没有出现 `[店铺名]` 类问题（`契约.py:242-261`）；库连不上时加 `--no-db` 沿用现有 CSV（`每日对账.py:166`）。
4. **加的店没进看板列**：看板列序由 `[店铺] list` 顺序生成（`写入日监控.py:52`），改完要重写一次看板才会出现新列；`main` 换人时它必须同时排到 `list` 第一位。
5. **改了 `[平台]`**：先确认 `平台/<site>/<product>/` 与 `平台/<site>/配置/<product>.ini` 都真实存在，否则下一次启动就报「找不到平台配置文件」（`项目配置.py:46-50`）。
6. **改完 webhook**：跑一次通知测试（`自动对账.py:168` 那条测试消息路径），因为地址格式不合法时是静默退回小助手（`通知.py:40-43`），光看退出码看不出来。
